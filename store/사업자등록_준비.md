# 사업자등록 준비 (개인사업자 · 부모님 자가 주소)

> 서류 요건은 세무서마다 조금 달라요. 홈택스 신청 화면의 안내와 세무서 문의(국번 없이 126)로 마지막에 한 번 확인하세요.

## 1. 신청서에 넣을 값 (홈택스 > 사업자등록 신청)
| 칸 | 넣을 값 |
|---|---|
| 사업자 유형 | 개인 · **간이과세자** (연 매출 1억 400만 원 미만) |
| 상호 | CHIEUN Studio |
| 사업장 소재지 | 부모님 자가 주소 (등기부등본의 주소와 똑같이) |
| 업종 1 (주업종) | 응용 소프트웨어 개발 및 공급업 (홈택스 업종 검색에서 코드 확인) |
| 업종 2 | 전자상거래 소매업 (통신판매) (업종 검색에서 코드 확인) |
| 개업일 | 신청하는 날 또는 앞으로의 날짜 |
| 사업장 구분 | 자가 소유가 **아니므로** "타인 소유 (무상 사용)"으로 선택, 소유자는 부모님 |
| 임대차 | 없음 (무상 사용) |

## 2. 서류 (부모님 자가 · 무상 사용일 때 보통 필요한 것)
- [ ] 부모님 **신분증 사본**
- [ ] 아래 **사용 승낙서** (부모님 서명 또는 도장)
- [ ] (요청 시) 등기부등본 — 정부24나 인터넷등기소에서 열람 가능, 소유자 확인용
- [ ] 치은 본인 신분증, 공동인증서 또는 간편인증

```

위 사업장을 사용인이 사업 목적(응용 소프트웨어 개발 및 공급업, 전자상거래 소매업)으로
무상으로 사용하는 것을 승낙합니다.

작성일: 2026년 __월 __일
소유자 서명(인): ________
```
(주민등록번호 뒷자리는 적지 마세요. 세무서가 요청하면 그때 따로 제출해요.)

## 4. 사업자등록 뒤에 할 일
1. 통신판매업 신고: 정부24 또는 관할 구청(의정부시 관련 부서). 사업자등록증 + 구매안전서비스 이용확인증(토스페이먼츠에서 발급)이 필요해요. 신고 비용은 없어요(면허세만 확인).
2. 토스페이먼츠 가입, 클라이언트 키·시크릿 키 발급.
3. Firebase Blaze 전환 → `functions` 배포 → `billing.js`의 `on`을 true로.
4. `terms.html`, `privacy.html`, 사이트 하단에 사업자 정보(상호, 대표자, 사업장 주소, 사업자등록번호, 통신판매업 신고번호, 연락처) 채우기.
5. 구글 플레이 개발자 계정의 사업자 주소 증빙은 사업자등록증으로 진행.

## 5. 주의
- 부모님 댁 주소는 약관·결제 화면·사이트 하단에 공개돼요. 부담되면 나중에 사업장 이전 신고(홈택스)로 비상주 사무실 등으로 바꿀 수 있어요.
- 부모님이 건강보험 피부양자라면, 사업소득이 생겼을 때 자격 변동이 있을 수 있어요. 소득이 생기면 건강보험공단(1577-1000)에 확인하세요.
- 간이과세자는 부가세 신고가 1년에 한 번이에요. 신고 기한(다음 해 1월)을 달력에 적어 두세요.
