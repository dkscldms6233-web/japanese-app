# 테스터 모집 문구 (카톡·단톡방에 그대로 보내세요)

## 1단계: 구글 계정 이메일 받기
```
안녕하세요! 제가 만든 일본어 공부 앱 "술술 일본어"를 안드로이드 폰에서 테스트해 주실 분을 찾고 있어요.
(안드로이드 폰만 가능해요. 아이폰은 안 돼요 ㅠㅠ)

해 주실 일은 간단해요.
1) 구글 계정 이메일 주소(gmail)를 저에게 알려 주세요.
2) 제가 보내 드리는 링크를 눌러 "테스터 되기"를 누르세요.
3) 플레이스토어에서 앱을 설치하세요.
4) 14일 동안 설치된 상태로 두시고, 가끔 열어서 써 봐 주세요.

* 14일 동안 계속 참여해 주셔야 정식 출시를 할 수 있어서, 중간에 앱을 지우지 않으면 정말 큰 도움이 돼요!
* 불편한 점이나 이상한 단어가 있으면 알려 주세요 🙏
```

## 2단계: 구글이 준 참여 링크를 보낼 때
```
테스터 참여 링크예요. 아래 순서대로 해 주세요!
1) 안드로이드 폰에서 이 링크를 눌러요: (여기에 콘솔의 참여 링크 붙여 넣기)
2) "테스터 되기"를 눌러요. (처음에 구글 계정을 골라야 해요)
3) 화면에 나오는 "Google Play에서 다운로드" 링크로 앱을 설치해요.
4) 앞으로 14일 동안 앱을 지우지 말고 가끔 열어 봐 주세요.
감사합니다!
```

## 3단계: 중간에 안부 묻는 문구 (7일쯤 뒤)
```
테스트 도와주셔서 고마워요! 아직 앱 설치돼 있죠? 14일이 지날 때까지만 그대로 두시면 돼요.
써 보시고 불편했던 점이나 이상한 단어, 화면 있으면 아무거나 편하게 알려 주세요 😊
```

## 모집 팁
- **14~16명**을 모으세요. 중간에 빠지는 사람이 생길 수 있어서 12명을 딱 맞추면 위험해요.
- 안드로이드가 아닌 분은 도울 수 없어요(아이폰 불가).
- 구글 계정 이메일은 테스터 목록에만 쓰고, 다른 곳에 쓰지 마세요. 받은 이메일은 친구들 개인정보라서 조심해서 보관하세요.
- 참여 링크는 비공개 테스트 트랙을 만들고 테스터 목록을 만든 뒤에 콘솔에서 볼 수 있어요. 목록에 이메일을 넣은 사람만 설치할 수 있어요.
