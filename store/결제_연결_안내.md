# 씨앗 구매 연결 안내 (토스페이먼츠 웹 결제)

구글 플레이 결제 대신 **웹에서 토스페이먼츠로 직접 결제**하는 방식이에요. (구글 수수료 15~30% 대신 결제 대행 수수료 3% 안팎. 요율은 계약 때 확인하세요.)
앱은 구글 플레이에 올리지 않고 웹·홈 화면 추가로만 배포하는 것이 전제예요. 플레이에 올리면 앱 안 디지털 상품 결제는 구글 결제 정책을 따라야 해서 웹 결제가 정책과 충돌할 수 있어요(확인 필요).

## 코드가 있는 곳
- `billing.js` — 앱 쪽 (구매 버튼, 토스 결제창 열기, 돌아왔을 때 승인 요청). 지금은 `CFG.on=false`라서 상점에 "준비 중"만 보여요.
- `functions/index.js` — 서버 (주문 만들기 `createOrder`, 결제 승인 + 지급 `confirmOrder`). **아직 배포 안 함.**
- `firestore.rules` — 구매 기록(`orders`, `wallets`)은 본인만 읽고, 쓰기는 서버만 가능.
- `terms.html` — 이용약관·환불 안내 (초안, 사업자 정보 칸이 비어 있어요). `privacy.html`에는 구매 기록 항목을 넣었어요.

## 가격 (부가세 10% 포함, 서버 `PACKS`가 기준)
| 상품 | 가격 |
|---|---|
| 씨앗 100개 | 1,100원 (공급가 1,000원 + 부가세 100원) |
| 씨앗 300개 | 2,750원 |
| 씨앗 700개 | 5,500원 |
| 씨앗 1,500개 | 11,000원 |
- 첫 구매 보너스: 구매한 개수의 50% (한 계정에 한 번). `functions/index.js`의 `FIRST_BONUS_RATE`.
- 가격을 바꿀 때는 `functions/index.js`의 `PACKS`와 `billing.js`의 `packs`(화면 표시용)와 `terms.html`을 같이 고쳐요.

## 켜기까지 순서 (직접 하실 것은 ★)
1. ★ **개인사업자 등록**(홈택스)과 **통신판매업 신고**(구청). 간이과세·일반과세 중 무엇이 맞는지는 세무서·세무사에게 확인하세요.
2. ★ **토스페이먼츠 가입.** 이메일만으로 가입하면 **테스트 키**를 받을 수 있어요(사업자 없이 시험 가능). 실제 결제는 전자결제 계약(사업자 필요)이 끝나야 해요.
3. ★ **Firebase 요금제를 Blaze로 변경** (Functions에 필요. 쓴 만큼만 내고, 이 정도 규모는 무료 한도 안일 가능성이 커요. 예산 알림을 꼭 걸어 두세요).
4. 서버 배포 (키는 코드에 쓰지 않아요):
   ```bash
   cd functions && npm install && cd ..
   npx firebase-tools functions:secrets:set TOSS_SECRET_KEY    # 토스 시크릿 키(test_sk_…)를 붙여넣기
   npx firebase-tools deploy --only functions,firestore:rules
   ```
5. `billing.js`에서 `clientKey`에 **클라이언트 키**(`test_ck_…`)를 넣고 `on:true`로 바꿔 배포.
6. **토스 테스트 결제**로 시험: 구매 → 결제창 → 돌아옴 → 씨앗 도착 → 같은 주소 새로고침해도 두 번 안 들어오는지 확인. 첫 구매 보너스가 한 번만 붙는지도 확인.
7. `terms.html`의 사업자 정보 입력(상호·대표자·사업자번호·통신판매업 신고번호·주소·연락처), 시행일 입력. 약관은 법률 검토를 받으면 더 안전해요.
8. 실서비스 키(`live_ck_…`, `live_sk_…`)로 바꾸고 소액으로 실제 결제·환불을 한 번 해 봐요.

## 결제 흐름
앱 → `createOrder`(서버가 가격·개수 결정) → 토스 결제창 → 앱으로 돌아옴(`?pay=ok&paymentKey…`) → `confirmOrder`(서버가 토스 승인 API 호출 + 금액 검증 + 중복 지급 방지) → 씨앗이 이 기기에 들어옴.

## 점검한 것 / 못 한 것
- 서버 로직은 가짜 데이터베이스·가짜 토스로 시험했어요(금액 위조, 남의 주문, 승인 실패, 같은 주문 두 번, 첫 구매 보너스 한 번). 모두 통과.
- 앱 쪽은 가짜 로그인·가짜 결제창으로 "구매 → 돌아옴 → 지급" 흐름을 확인했어요.
- **실제 토스 결제창·실제 승인은 한 번도 시험하지 못했어요.** 토스 문서에서 확인한 값(결제 승인 `POST /v1/payments/confirm`, 인증은 시크릿 키 뒤에 `:`를 붙여 base64한 Basic 방식, 결제창 `requestPayment` 파라미터)을 따라 썼지만, 스크립트 주소(`https://js.tosspayments.com/v2/standard`)와 일부 동작은 테스트 키로 꼭 확인하세요.
- 서버(Functions)는 배포하지 않았어요. Firebase Functions의 호출 주소(`asia-northeast3-surasura-nihongo.cloudfunctions.net`)도 배포 뒤 실제 주소와 맞는지 확인이 필요해요.

## 알아 둘 한계
- **씨앗은 아직 이 기기에 저장돼요.** 서버는 "무엇을 샀는지" 기록만 남겨요(문의하면 확인·복구 가능). 앱 데이터를 지우면 산 씨앗도 사라질 수 있어요. 정식 판매 전에 씨앗을 계정(서버)에 저장하는 작업이 따로 필요해요.
- **환불 시 씨앗 회수는 수동이에요.** 토스 콘솔에서 결제를 취소해도 이미 들어간 씨앗은 자동으로 빠지지 않아요.
- **웹훅은 아직 없어요.** 결제 도중 앱이 꺼진 경우에는 같은 기기에서 앱을 다시 열면 이어서 처리해요(임시 저장). 다른 기기에서는 처리되지 않을 수 있어요.
- 한국 소비자 가격은 부가세 포함으로 표시해야 해요. 세금 신고·정산은 세무서·세무사에게 확인하세요.
