# 구글 플레이 출시 체크리스트 (술술 일본어)

★ = 직접 하셔야 하는 일 / 🤖 = 제가 이미 해 둔 일 / ⚠ = 먼저 알아 두실 점
예상 기간: **개인 계정이면 최소 3주 이상** (비공개 테스트 14일이 필수라서요).

---

## 0. 먼저 알아 두실 점
- ⚠ **새 개인 개발자 계정(2023년 11월 13일 이후 만든 계정)은 정식 출시 전에 "비공개 테스트"를 해야 해요.** 테스터 **12명 이상**이 **14일 연속** 테스트에 참여(옵트인)해야 정식 출시를 신청할 수 있어요. (구글 도움말 기준. 정책은 바뀔 수 있으니 콘솔 안내를 확인하세요.) 교육 현장 사람들과 친구들에게 부탁해 두면 좋아요.
- ⚠ **플레이 앱 안에서는 씨앗 구매(웹 결제)를 숨겼어요.** 구글 정책상 앱 안의 디지털 상품 결제는 구글 결제만 쓸 수 있어서, 웹 결제를 앱 안에서 보여 주면 정책 위반이 될 수 있어요. 지금은 플레이 앱에서 상점의 "씨앗 사기" 구역이 안 보여요(웹/홈 화면 추가 버전에서만 나올 예정). 나중에 플레이 앱에서도 팔고 싶으면 구글 결제를 붙여야 해요.
- ⚠ **Edge 음성(단어·글자·청해·뉴스)은 마이크로소프트가 공식으로 허용한 방식이 아니에요.** 플레이 출시 때 걸리지는 않지만, 공개 배포는 약관 위반일 수 있어요. 출시 전에 정식 음성 서비스(Azure 등)나 VOICEVOX 같은 이용 규약이 분명한 음성으로 바꿀지 결정해 주세요.
- ⚠ 개인 계정이어도 스토어에 **개발자 연락처(이메일 등)가 공개**될 수 있어요. 별도 이메일(surasura.support@gmail.com)을 쓰고 있어서 괜찮아요.

## 1. 개발자 계정 만들기 ★
1. 구글 계정에 **2단계 인증**을 켜요. (전에 여기서 막혔다고 하셨어요.)
2. https://play.google.com/console 접속 → 개발자 계정 만들기. 등록비 **25달러**(1회, 카드 필요).
3. 계정 유형: **개인**으로 가는 게 가장 쉬워요. (조직은 사업자 확인·D-U-N-S 번호가 필요해요.)
4. 본인 확인: 신분증, 주소, 전화번호 인증. 승인까지 며칠 걸릴 수 있어요.
- 무료 앱이고 구글 결제를 쓰지 않으므로 **결제 프로필(판매자 계정)은 필요 없어요.**

## 2. 앱 만들기 ★
- Play Console → 앱 만들기: 이름 `술술 일본어 - 단어·한자·문법·청해`, 언어 한국어, **앱**, **무료**.
- 🤖 소개 글은 `store/등록정보_초안.md`에 있어요. 복사해서 붙여 넣으면 돼요. (제목에 JLPT를 뺀 이유: JLPT는 시험 주최 측의 이름이라 앱 제목에 쓰면 상표 문제가 될 수 있어서, 설명 글에서만 "비공식 학습 앱"이라는 문구와 함께 썼어요.)

## 3. 앱 설치 파일(AAB) 올리기 ★
- 🤖 파일: `store/apk/surasura-nihongo-v1.0.1.aab` (새 수채화 아이콘, 같은 서명 키로 만들었어요).
- 콘솔 → 테스트 → **비공개 테스트** → 새 출시 만들기 → AAB 업로드.
- 처음 올릴 때 **"Play 앱 서명"**을 켜라고 해요(권장, 켜세요). 그러면 구글이 실제 서명 키를 따로 관리해요.
- ⚠ **서명 키 파일은 꼭 백업하세요:** `store/apk/out/signing.keystore`와 `signing-key-info.txt`(비밀번호 들어 있음). 업로드 키라서 잃어버리면 업데이트가 어려워져요. USB나 개인 클라우드에 따로 보관하세요. 남에게 보내지 마세요.

## 4. 주소창 없애기 (assetlinks 추가) ★ + 🤖
- Play 앱 서명을 켜면 콘솔 → 설정 → **앱 무결성**(또는 앱 서명)에 **"앱 서명 키 인증서 SHA-256 지문"**이 나와요.
- 그 지문을 알려 주세요. 제가 `.well-known/assetlinks.json`에 추가해서 배포해 드릴게요. 이걸 안 하면 설치한 앱 위에 크롬 주소창이 보여요.
- (현재 파일에는 업로드 키 지문이 들어 있어요.)

## 5. 스토어 등록 정보 ★
- 🤖 앱 아이콘 512×512: `icon-512.png`
- 🤖 그래픽 이미지 1024×500: `store/feature-graphic.png` (새 아이콘 반영)
- 🤖 폰 스크린샷 7장(1080×1920): `store/스크린샷/` (홈, 단어장, 경어, 퀴즈, 문법, 게임, 글자 배우기). 최소 2장, 최대 8장 올릴 수 있어요. 보여 주고 싶은 순서대로 올리세요.
- 🤖 간단한 설명(80자)·자세한 설명·연락처: `store/등록정보_초안.md`
- 카테고리: 교육. 태그는 콘솔에서 고르세요.

## 6. 앱 콘텐츠 설문 ★ (콘솔 → 정책 → 앱 콘텐츠)
`store/등록정보_초안.md`의 "앱 콘텐츠 설문"을 참고하세요. 핵심 답변:
- **개인정보처리방침 주소:** https://surasura-nihongo.web.app/privacy.html
- **광고:** 아니요
- **앱 액세스:** 로그인 없이 대부분 이용 가능(게스트). 🤖 심사용 **테스트 계정을 만들어 뒀어요**(이메일 인증 완료). 계정 정보와 설명란에 붙여 넣을 안내문은 `store/심사용_테스트계정.md`에 있어요(깃에는 안 올라가요). 심사가 끝나면 Firebase 콘솔에서 삭제하세요.
- **콘텐츠 등급 설문:** 사용자끼리 대화하는 기능(친구 채팅)이 있다고 답해야 해요. 폭력·성적 내용 없음.
- **대상 연령:** 13세 이상 권장(어린이 대상 앱 아님). 개인정보처리방침에 만 14세 미만 가입 안내가 있어요.
- **데이터 보안 양식:** 수집 항목 = 이메일, 이름(닉네임), 앱 활동(학습 기록), 사용자 ID. 목적 = 앱 기능, 계정 관리. 제3자 공유·판매 없음. 전송 중 암호화 = 예. **사용자가 삭제를 요청할 수 있음 = 예.**
- **계정 삭제:** 🤖 앱 안(내 계정 → 계정 삭제)과 웹(privacy.html 4번) 모두 있어요. 구글은 둘 다를 요구하고, 웹 주소는 위 개인정보처리방침 주소를 쓰면 돼요.
- **금융 기능·건강·정부 앱·뉴스 앱:** 모두 해당 없음. (뉴스 읽기는 학습용 글이라 "뉴스 앱"이 아니라고 답하세요.)

## 7. 정책 점검 결과 🤖
| 항목 | 상태 |
|---|---|
| 계정 삭제 기능(앱 안·웹) | 있음 |
| 사용자 신고 기능(닉네임·대화) | 있음 |
| 앱 권한(위치·연락처·카메라·마이크) | 요청 안 함 |
| 앱 안 결제 | 플레이 앱 안에서는 숨김 |
| 광고 | 없음 |
| 오픈소스 표기(KanjiVG, Noto Emoji) | 앱·개인정보처리방침에 표기됨 |
| 뉴스 출처 표기 | 있음 (일본 정부 공개 자료 이용 규약 안내) |
| JLPT 비공식 고지 | 소개 글·이용약관에 있음 |
- ⚠ 확인 필요: 앱 안 대화 기능은 "사용자 생성 콘텐츠" 정책 대상이에요. 신고는 있지만, **차단 기능**은 따로 없어요(친구 삭제는 있음). 심사에서 요구하면 추가해야 할 수 있어요.

## 8. 비공개 테스트 운영 ★
1. 콘솔 → 비공개 테스트 → 테스터 목록 만들기: 테스터 **12명 이상**의 구글 계정 이메일을 추가하거나 구글 그룹을 연결.
2. 콘솔이 주는 **참여 링크**를 테스터에게 보내요. 테스터가 링크로 들어가 **"테스터 되기"를 눌러야** 해요. 그다음 플레이스토어에서 앱을 설치해요.
3. **14일 동안 계속 참여 상태**여야 해요(중간에 빠지면 다시 계산). 여유 있게 14~16명을 모으세요.
4. 테스터에게 가끔 앱을 써 보고, 불편한 점이 있으면 알려 달라고 부탁하세요.

## 9. 정식 출시 신청 ★
- 14일이 지나면 콘솔 → 대시보드 → **프로덕션 액세스 신청**. 테스트 중 받은 의견과 수정한 내용을 묻는 질문에 답해요.
- 심사는 며칠~1주 정도 걸려요. 통과하면 프로덕션 트랙에 올려 출시해요. 처음에는 **단계적 출시(일부 사용자 먼저)**를 선택해도 좋아요.

## 10. 출시 후
- 앱 내용(단어·문법·화면)은 **사이트를 배포하면 바로 반영**돼요. 설치 파일은 다시 올릴 필요가 없어요.
- 설치 파일(AAB)은 아이콘·이름·버전이 바뀔 때만 다시 만들어 올려요. (제가 만들어 드려요. 버전 번호를 올려야 해요.)
- 씨앗 구매는 웹 결제만 열렸을 때 웹/홈 화면 추가 버전에서만 나와요. 플레이 앱에도 열려면 구글 결제를 따로 붙여야 해요.

6. ★ 비공개 테스트 시작 → 14일 뒤 프로덕션 신청
