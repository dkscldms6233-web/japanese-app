개인정보처리방침

すらすら日本語(술술 일본어) · 시행일: 2026년 11월 23일

술술 일본어(이하 "앱")는 일본어 시험(JLPT) 공부를 돕는 앱이에요. 이 방침은 앱이 어떤 정보를 어떻게 쓰고 지키는지 알려 드려요.

1. 모으는 정보

정보언제왜
학습 기록(푼 문제, 틀린 단어, 저장한 단어, 점수, 레벨, 참새 꾸미기 상태)앱을 쓸 때이어서 공부하고 복습을 도와주려고
이메일 주소, 닉네임, 비밀번호(암호화되어 저장)회원가입할 때(선택)로그인과 여러 기기 동기화
주간 리그 점수, 친구 코드, 응원·선물·대화 내용커뮤니티 기능을 쓸 때(선택)친구·리그·응원 기능 제공
문의·신고 내용문의나 신고를 보낼 때오류 확인과 답변
구매 기록(주문번호, 상품, 금액, 결제 일시, 결제 상태)씨앗을 구매할 때결제 확인, 환불·문의 처리, 법령상 보관 의무(전자상거래법상 대금결제·재화 공급 기록 5년)

회원가입을 하지 않고 "게스트"로 쓰면 학습 기록은 이 기기에만 저장되고 서버로 보내지 않아요.

2. 정보를 쓰는 목적

  • 학습 기록 저장과 여러 기기에서 이어서 공부하기
  • 커뮤니티 기능(리그, 친구, 응원) 제공
  • 오류 확인과 서비스 개선

광고를 보여 주지 않고, 정보를 판매하거나 광고 목적으로 제3자에게 주지 않아요.

3. 정보가 저장되는 곳

로그인한 계정의 정보는 구글 Firebase(Authentication, Cloud Firestore)에 저장돼요. 정보는 암호화된 연결(HTTPS)로 전송되고, 본인 학습 기록은 본인만 읽고 쓸 수 있도록 접근 규칙을 걸어 두었어요. Firebase는 구글이 운영하는 서비스라 정보가 한국 밖의 서버에 저장될 수 있어요.

4. 보관과 삭제

정보는 계정을 유지하는 동안 보관하고, 계정을 삭제하면 지워요.

  • 앱 안에서 삭제: 앱 위쪽의 프로필 → "내 계정" → 계정 삭제를 누르고 비밀번호를 입력하면, 이메일 계정과 클라우드의 학습 기록, 친구 코드가 삭제돼요.
  • 앱을 쓸 수 없을 때: 아래 문의 방법으로 가입한 이메일과 함께 삭제를 요청하면 확인 후 삭제해요.

다른 친구에게 이미 보낸 응원이나 대화는 상대방 화면에 남아 있을 수 있어요. 게스트로 쓴 기록은 기기에만 있어서 앱을 지우거나 브라우저 데이터를 지우면 사라져요.

5. 어린이

만 14세 미만 어린이는 보호자의 동의 없이 회원가입을 하지 말아 주세요. 게스트로는 가입 없이 쓸 수 있어요.
